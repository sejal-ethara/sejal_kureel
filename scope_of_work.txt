FENRIR ARENA - ONLINE GAMING WEBSITE
Scope of Work

------------------------------------------------------------
1. PAGES TO BUILD (8 PAGES TOTAL)
------------------------------------------------------------
1. Home Page (index.html)
   - Hero banner displaying the heading "Fenrir Arena"
   - Tagline "Play. Compete. Conquer." displayed verbatim
   - Featured games section showing exactly 4 games
   - "Browse All Games" button linking to library.html
   - Layout follows the client-provided reference_image.png

2. Game Library Page (library.html)
   - Grid containing all 6 games
   - Category filter buttons: Arcade, Puzzle, Racing
   - Each game card shows: thumbnail image, game title, category tag

3. Individual Game Page (game.html)
   - HTML5 Canvas element where the game runs
   - Game title and short description
   - "How to Play" section
   - Leaderboard table showing top 10 scores, sorted highest to lowest

4. Login Page (login.html)
   - Email input field
   - Password input field
   - Button labelled "Login"
   - Link to Sign Up Page

5. Sign Up Page (signup.html)
   - Username input field
   - Email input field
   - Password input field
   - Button labelled "Create Account"
   - Link to Login Page

6. User Profile Page (profile.html)
   - Display the logged-in user's username
   - Table listing the user's best score for each game

7. About Page (about.html)
   - Text section describing Fenrir Arena
   - Tagline "Play. Compete. Conquer." displayed verbatim

8. Contact Page (contact.html)
   - Name input field
   - Email input field
   - Message input field
   - Button labelled "Send Message"

------------------------------------------------------------
2. GAMES TO BUILD (6 TOTAL)
------------------------------------------------------------
Category: Arcade
- Brick Breaker: Left/Right arrow keys move the paddle
- Snake Classic: arrow keys change direction

Category: Puzzle
- Memory Match: mouse click flips cards
- 2048 Tile Merge: arrow keys merge tiles

Category: Racing
- Endless Runner: spacebar triggers jump
- Sky Dash: arrow keys steer, spacebar boosts

Each game must run inside an HTML5 Canvas element, must be
embedded on its own Individual Game Page, and must display the
player's current score during play.

Score Submission: when a game ends, the final score must be sent
to the backend save score endpoint. The score is saved only if
the player is logged in.

------------------------------------------------------------
3. BACKEND REQUIREMENTS
------------------------------------------------------------
Framework: Node.js with Express
Database: SQLite

Endpoints:
- Sign up: accepts username, email, and password; stores
  password as a hashed value
- Login: accepts email and password; returns a session that
  persists while the browser tab is open
- Save score: accepts username, game name, score value, and
  date; stores the record
- Leaderboard: accepts a game name; returns the top 10 scores
  for that game, sorted highest to lowest

Data fields:
- User account: username, email, hashed password
- Score record: username, game name, score value, date
