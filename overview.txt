FENRIR ARENA - ONLINE GAMING WEBSITE
Project Overview

Client: Fenrir Project
Product Name: Fenrir Arena
Category: Web Development
Project Type: Online Gaming Website (Browser-based Casual Gaming Portal)

------------------------------------------------------------
1. WHAT IS BEING BUILT
------------------------------------------------------------
Fenrir Arena is a browser-based gaming portal where visitors can:
- Browse a catalog of casual games organized by category.
- Play games directly in the browser without downloads.
- Create an account, log in, and track personal high scores.
- View a global leaderboard for each game.
- Read game instructions before playing.

The website is front-end focused with a lightweight backend for
user accounts, scores, and leaderboards.

------------------------------------------------------------
2. WHO THIS IS FOR
------------------------------------------------------------
Fenrir Arena targets casual players aged 13 and above who want
quick, browser-based games without app installation. The site
must work on desktop browsers and mobile browsers.

------------------------------------------------------------
3. CORE PAGES
------------------------------------------------------------
- Home Page
- Game Library Page
- Individual Game Page (with embedded game + leaderboard)
- Login Page
- Sign Up Page
- User Profile Page (shows player's saved scores)
- About Page
- Contact Page

------------------------------------------------------------
4. CORE FEATURES
------------------------------------------------------------
- Account creation and login (email + password)
- Game catalog with category filters
- Embedded playable games (HTML5 Canvas based)
- Score saving per user per game
- Leaderboard showing top 10 scores per game
- Responsive layout for mobile and desktop

6. SCOPE BOUNDARY
------------------------------------------------------------
This project covers design, frontend pages, and basic backend
wiring for accounts/scores. It does not include payment
processing, multiplayer real-time gameplay, or mobile app
versions (iOS/Android native apps).
